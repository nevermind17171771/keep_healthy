# KEEP HEALTHY 4.5

개인 운동 기록 앱의 전체 재구현입니다. 기존 GitHub Pages 앱에서 사용하던 운동 사전과 루틴을 바탕으로, 기록·근육 지도·기구 설정·분석·계정 저장을 연결했습니다.

현재 앱은 [KEEP HEALTHY](https://keep-healthy-deric-v4.matteblack.chatgpt.site)에 공개 배포되어 있습니다. 계정별 동기화 데이터는 인증된 본인만 조회할 수 있습니다. 이 브랜치는 GitHub Pages용 정적 HTML이 아니라 Cloudflare Workers + D1 기반 앱입니다. 기존 `main`의 서비스를 교체하기 전에 새 앱에서 기록 이관과 실기기 사용을 확인해야 합니다.

## 사용할 수 있는 기능

- 382개 중복 제거 운동, 15개 기본 루틴, 이름·초성·부위·장비 검색, 즐겨찾기
- 앞·뒷면 근육 도식과 주동근/보조근 구분. 광배근, 등 상부, 전면/측면/후면 삼각근의 분류 개선
- 중량·맨몸 추가 중량·보조 중량·시간·유산소 기록 방식 구분
- 워밍업·본세트·드롭세트, RPE, 슈퍼세트, 지난 기록, 휴식 타이머와 일시정지
- 기구별 중량 이력, 좌석/그립 메모, 최소 증량 단위, 보수적인 다음 중량 제안
- 루틴 생성·복제·편집, 주간 계획, 과거 운동 입력·수정·삭제·복원
- 주간 본세트, 부위별 세트 분포, 종목/기구별 추정 1RM, 실제 신체 기록과 별도 목표 체중
- JSON 가져오기/백업, CSV, 세트별 기록·근육 지도를 담은 오운완 PNG 카드, 사진 저장용 공유창
- IndexedDB 임시 저장, 계정별 D1 저장, 충돌 감지·합치기, 미완료 운동 복구본, 일별 변경 전 백업
- 모바일 레이아웃, 다크/라이트 테마, 홈 화면 설치, 오프라인 앱 캐시, 운동 종료 후 업데이트

## 기존 기록 가져오기

1. 기존 앱에서 **내보내기**를 눌러 JSON 백업을 받습니다.
2. 새 앱의 **설정·데이터 → 기록 가져오기**에서 파일을 선택합니다.
3. 운동/신체 기록 수를 확인하고 **백업 후 합치기**를 누릅니다.
4. 기존 운동 몇 건의 날짜·세트·시간을 비교합니다. 동기화 완료를 확인한 후 새 앱을 홈 화면에 추가합니다.

새 주소에서 기존 주소의 기기 저장소를 직접 읽을 수 없으므로 파일 이관이 필요합니다. 원본 JSON은 `legacyArchive`로 보관합니다. 기존 앱의 유산소 지표(경사, 칼로리, 층 수 등)는 해당 입력 필드로 옮기며 원본도 보관합니다. 영양·수분 기록은 원본에 보관되며 별도 입력/분석 화면은 제공하지 않습니다. 이전 버그로 숫자가 된 `20:30`의 초 단위는 이미 소실되어 복구할 수 없습니다. 원본에서 단위가 초인 종목과 미터인 거리는 별도로 변환합니다.

## 개발과 검증

Node.js 24 기준입니다.

```sh
npm ci
npm run typecheck
npm test
npm run build
npm run test:worker
```

- `npm test`: 데이터 변환·계산·충돌·API 접근 통제와 7개 화면 렌더링을 검증합니다.
- `test:worker`: 빌드 결과를 실제 Workers 런타임(Miniflare)에서 실행하고 D1 마이그레이션, 익명 접근 거부, 인증된 저장/조회, HTML 진입점을 검증합니다.
- `wrangler.local.json`: 로컬 타입 생성 및 D1 마이그레이션용 설정입니다. 실제 사용자 데이터나 비밀키를 포함하지 않습니다.
- 배포는 Sites 관리 환경을 사용합니다. `.openai/hosting.json`의 논리적 D1 바인딩 `DB`를 유지합니다.
- `release/keep-healthy-v4`는 기존 Git 이력을 이어받습니다. 이전 앱의 소스는 Git 이력에서 조회할 수 있습니다.

## 출시 전 남은 확인

브라우저 접근 정책으로 실제 클릭·화면 크기별 시각 QA는 수행하지 못했습니다. 서버 렌더링 테스트는 실기기 E2E 테스트를 대체하지 않습니다. iOS Safari/Android Chrome에서 설치, 숫자 입력, 화면 잠금 후 복귀, 오프라인 재실행, 업데이트, 두 기기 충돌을 확인해야 합니다.

현재 동기화는 계정의 전체 상태를 보내며 요청 크기는 1.5MB로 제한됩니다. 큰 기록집은 백업 파일을 유지해야 하며, 장기 대용량 서비스에는 세션별 증분 동기화와 저장 구조 확장이 필요합니다. 로컬 기록은 해당 브라우저에 남으므로 개인 기기 사용을 전제로 합니다. PWA는 네이티브 백그라운드 알림이나 워치 연동을 제공하지 않습니다. 외부 AI, 결제, 건강 플랫폼 연동은 구현된 것처럼 표시하지 않습니다.

운동 설명과 근육 분류는 기록을 돕는 참고 정보입니다. 부위별 세트 수는 실제 근육 자극량이나 회복 진단이 아닙니다. 근육 도식의 세부 구획 한계와 출처는 [운동 데이터 설명](docs/exercise-data.md)을 참고하세요.

### 4.1 운동 중 편의 기능

- 휴식 종료 시 세 번 울리는 복싱 라운드 벨. 기기에서 합성하며 외부 오디오 다운로드가 없습니다. 설정에서 미리 들을 수 있습니다. 모바일 백그라운드 오디오를 보장하지 않습니다.
- 운동 상세와 진행 화면에서 종목명으로 YouTube 쇼츠 검색을 엽니다. 영상은 삽입하지 않으며 검색 결과가 쇼츠로만 제한되지는 않습니다. 필요하면 YouTube에서 Shorts 필터를 선택합니다.
- 트레드밀/인클라인/천국의 계단/사이클/로잉 등 기구별 입력. 단위는 화면에 표시하며 로잉 거리는 m, 저장·CSV 거리는 km로 통일합니다.
- 칼로리·수직 이동거리 등은 기구 표시값을 직접 기록합니다. 미입력과 0을 구별하고 추정값을 자동 생성하지 않습니다. 구간을 추가할 때 속도·경사·레벨만 이어받고 이전 구간의 누적 수치는 복사하지 않습니다.
- 추가 지표는 JSON/CSV, 기록 상세, 지난 기록, 서버 동기화에 포함됩니다. 기존 v4 클라이언트가 모르는 지표를 누락해 전송해도 서버의 해당 세트 지표를 유지하며, 최신 클라이언트의 명시적 빈 객체는 삭제로 인정합니다.


### 4.2 집중 기록과 기구별 설정

- 운동 중 기본 화면은 **집중 화면**입니다. 한 종목·한 세트, 이전 수행값과 오늘 목표, 큰 중량 버튼, 휴식 타이머를 함께 보여 줍니다. 상단 **전체 운동**에서 모든 세트와 종목 편집 기능을 사용할 수 있습니다.
- 진행 화면 또는 설정의 기구 목록에서 **입력 설정**을 엽니다. 유산소 항목 순서와 먼저 표시할 항목, 다음 운동에 채울 속도·경사·저항 기본값을 저장합니다. 시간·거리·칼로리 등의 수행 결과는 자동 복사하지 않습니다.
- kg/lb와 덤벨 한쪽/양쪽 합계를 선택합니다. 내부 중량과 분석·CSV의 `weight_kg`는 기존 기준(덤벨 한쪽 kg)을 유지하며, CSV에는 표시 중량·단위·기준을 별도 열로 제공합니다. 단위 변경만으로 운동량이 달라지지 않습니다.
- 경사는 %와 ° 사이에 변환합니다. 기구의 임의 경사 레벨은 별도 `incline_level`로 기록하며 %나 °로 추정하지 않습니다. 기존 `incline_percent` 데이터는 보존합니다.
- **지난 세트를 오늘 목표로**는 같은 헬스장·기구의 직전 본세트를 순서대로 참고 목표에 넣습니다. 이미 완료한 세트나 실제 입력값을 덮어쓰지 않습니다. **목표값 입력**을 누르면 미완료 세트에 수치를 채우고, 완료는 직접 체크합니다.
- 기록마다 표시 설정을 함께 저장합니다. 이후 기구 설정을 바꿔도 저장된 과거 기록의 표시 기준은 유지됩니다. 구버전 클라이언트가 새 필드를 생략해도 서버는 설정과 목표를 보존합니다.


### 4.3 프로그램 검토와 가져오기

루틴 화면의 프로그램 라이브러리에 가슴·어깨 우선 주 4회, 머신 중심 전신 주 3회, 상·하체 주 4회, 30분 압축 주 3회, 운동 복귀 주 3회를 추가했습니다. 순서·세트·반복 범위·휴식·구성 이유·주간 직접 세트와 보조 참여를 미리 보고 가져옵니다. 대체 후보는 동작 유형으로 제한하며 중량은 복사하지 않습니다. 단축 버전은 핵심 2–3종목 각 2세트, 가벼운 버전은 종목당 2세트와 RPE 6–7 출발점을 사용하며 개인의 회복을 자동 진단하지 않습니다.

기존 기본 루틴 15개의 과도한 세트, 짧은 휴식, 늦게 배치된 어깨 프레스, 힌지 후 바벨 로우를 교정했습니다. 선수 이름은 출처가 확인된 공식 프로그램으로 오인되지 않도록 제거했습니다. 개정본은 새 사용자 기본값이며 기존 사용자는 라이브러리에서 필요한 개정본만 새 루틴으로 추가합니다. 저장된 사용자 루틴·수행 기록은 자동 교체하지 않습니다.

주간 계획 교체는 체크한 경우에만 적용합니다. 휴식일은 홈에도 휴식으로 표시됩니다. 프로그램의 예상 시간은 보장하지 않으며 대기·워밍업에 따라 달라집니다. 복귀 계획은 통증 재활 처방이 아닙니다.

루틴 편집의 순서 점검은 고립운동 선행, 허리 피로 중복, 짧은 휴식과 많은 총 세트를 참고 안내합니다. 이 휴리스틱은 완전한 안전 검사나 근성장 최적화 보증이 아닙니다. 주동근/보조근 세트는 분리하며 개인 최적량 또는 실측 자극량으로 해석하지 않습니다. 실제 목표 반복 범위와 RPE 기준은 운동에 스냅샷으로 저장되어 증량 제안에 사용됩니다. 가벼운/복귀 계획에서는 이전 고중량을 자동 채우지 않습니다. 운동 중 대체 시 완료 기록이 있으면 원래 종목을 남기고 새 종목을 추가합니다.

설계 참고: ACSM 2026 resistance training position stand (https://pubmed.ncbi.nlm.nih.gov/41843416/), 운동 순서 메타분석 (https://pubmed.ncbi.nlm.nih.gov/32077380/), 휴식 간격 메타분석 (https://www.frontiersin.org/journals/sports-and-active-living/articles/10.3389/fspor.2024.1429789/full). 개별 프로그램은 이 원칙을 적용한 앱의 시작안이며 연구에서 직접 검증한 특정 처방이 아닙니다.

## 4.5 변경사항

- 횟수 입력에 1회 단위 +/− 버튼을 추가했습니다.
- 휴식 완료 안내는 소리 재생 성공 여부와 별개로 표시되며 직접 닫을 때까지 남습니다. HTML 오디오와 Web Audio 재생 경로를 함께 사용하고 중단된 오디오 세션을 복구합니다.
- 설정 → 앱처럼 사용하기에서 벨 테스트, 알림 권한·배너 테스트, 5초 휴식 테스트를 제공합니다.
- 오운완 카드는 완료한 세트의 중량/횟수/세트, 유산소 측정값, 주동근/보조근 지도, 완료율, 입력된 RPE와 이전 동일 중량 비교를 담습니다. 긴 기록은 여러 PNG로 나눕니다.
- PNG를 미리 만든 뒤 사용자 탭에서 네이티브 공유창을 엽니다. iPhone에서 이미지 저장을 선택하면 사진 앱으로 저장할 수 있습니다. 웹앱이 사진첩에 직접 쓰거나 저장 성공을 확인하지는 못합니다.
- 현재 서버 예약 푸시는 구현되어 있지 않습니다. 앱이 중단/종료된 상태의 정시 알림은 보장하지 않습니다. 알림 권한 테스트 성공은 백그라운드 예약 푸시 지원을 의미하지 않습니다.

검증과 실기기 확인 항목은 [4.5 릴리스 기록](docs/RELEASE-4.5.md)에 정리했습니다.

### 오운완 카드 요약 개정

카드는 RPE·완료율·이전 비교를 제외하고 1080×1920 한 장으로 고정합니다. 완료한 본·드롭 세트의 같은 중량/횟수는 묶고, 서로 다르면 범위로 요약합니다. 시간·총 세트·중량 볼륨·근육 지도와 최대 8개 종목을 표시하며 초과 종목 수를 명시합니다. 유산소는 시간과 거리/스텝, 경사/층수 등 핵심 지표를 선택합니다. 워밍업은 별도 개수로만 표시합니다. 세부 기록은 앱에 그대로 남습니다.
